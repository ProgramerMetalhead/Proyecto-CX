# 📖 Un Cuento Para Ti ✨ - Carta Romántica de Disculpas

Una carta interactiva de disculpas diseñada como un **cuento de hadas infantil ilustrado**, construida con **React**, **Vite** y **Tailwind CSS**.

---

## 🌟 Características

- 📚 **Estilo Libro de Cuentos Infantil**: Textura de pergamino antiguo, lomo de libro encuadernado, marcos dorados, letras capitulares iluminadas y cintas de marcapáginas.
- 🔄 **Navegación de Páginas**: Botones intuitivos para **Avanzar** y **Retroceder**, indicador de páginas, navegación por puntos y atajos de teclado (flechas ◀ y ▶).
- 🎨 **Elementos Interactivos en Cada Capítulo**:
  - **Capítulo 1**: Cielo nocturno con estrellas interactivas que revelan mensajes dulces al tocarlas.
  - **Capítulo 2**: Nube gris interactiva que se disipa al tocarla para transformarse en un sol brillante, flores y arcoíris.
  - **Capítulo 3**: Sobre de carta vintage con sello de cera de corazón que se abre y despliega una nota sincera.
  - **Capítulo 4**: Cuatro pergaminos dorados con promesas concretas de cambio y cuidado emocional.
  - **Capítulo 5**: Desenlace interactivo con pregunta de perdón, explosión de confeti (`canvas-confetti`) y respuestas tiernas.
- 🎵 **Efectos de Sonido Mágicos (Web Audio API)**: Sonido realista de pasar página, campanitas de cuento de hadas y arpegios mágicos (100% nativo, sin dependencias de archivos externos).
- 💖 **Botón "Mandar Amor"**: Dispara corazones flotantes por la pantalla.
- ✍️ **Personalizador de Nombres**: Botón para cambiar fácilmente el nombre de tu pareja y el tuyo ("Para:" y "De:").

## 🚀 Cómo Iniciar el Proyecto

1. Abrir la terminal en esta carpeta:
   ```bash
   cd C:\Users\Cristobal\Desktop\Carta
   ```

2. Ejecutar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abrir en tu navegador el enlace mostrado (normalmente `http://localhost:5173`).
